# laptop-market-analytics-with-AI
لوحة تحليل سوق أجهزة الكمبيوتر المحمولة التفاعلية، تحلل 1273 جهازًا من 19 علامة تجارية. تتضمن مؤشرات رئيسية، ومخططات توزيع العلامات التجارية/أنظمة التشغيل، ومخططات تشتت أسعار ذاكرة الوصول العشوائي، وجدول بيانات قابل للفرز والترقيم بالكامل، وفلاتر بحث فورية حسب العلامة التجارية/النوع.
